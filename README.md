# Minesweeper C++

Un joc **Minesweeper** realizat în C++, care rulează direct în consolă.

## Funcționalități

* 4 niveluri de dificultate
* generare aleatorie a minelor
* prima alegere nu poate fi o mină
* posibilitatea de a deschide sau marca poziții
* deschiderea automată a zonelor libere folosind **BFS**
* verificarea automată a câștigului

## Dificultăți

* Easy — `8x8`
* Medium — `12x12`
* Hard — `16x16`
* Insane — `20x20`

## Rulare

Programul poate fi compilat cu un compilator C++:

```bash
g++ main.cpp -o minesweeper
```

Apoi rulează executabilul și urmează instrucțiunile din consolă.
